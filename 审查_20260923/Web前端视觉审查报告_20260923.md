- **审查对象**：http://127.0.0.1:5174（React 19 + Vite SPA，`05_原型/frontend`，后端 8765 实时数据）
- **审查时间**：2026-09-23 · 两轮完整审查 + 交叉验证
- **方法与分工**：`product-design:audit`（UX 流程/可达性）＋ `product-design:design-qa`（工艺保真度/对比度实算/CSS token 对照）＋ `browser-use:web-gui-tester`（黑盒交互/边界/响应式/控制台遥测）＋ `visual-judge`（渲染截图验收判定，两轮共 4 个判定代理、36 张截图逐张放大细读）

## 一、总体结论

产品整体架构清晰（数据中心→工作台→模型配置三模块），数值自洽性经两态交叉验算全部对上，证据可追溯呈现是全站最强项。但存在 **1 个模态层叠倒挂、1 个口径联动失步、1 处图表标签不可读** 三个 P1 级缺陷，以及系统性低对比度辅助文本、若干模板拼接型文案重复。视觉工艺（间距/边框/按钮体系）基本统一，主要短板集中在：图表信息完备性、异常与等待反馈、辅助文本可读性、移动端适配。

## 三、P2（19 条，按主题归组）

**图表信息设计**
1. 成本趋势图无任何图例：预测虚线、「实验性波动区间」无法从图上辨识；且 y 轴固定 0 起量，把 16.9–18.4 的数据与预测区间压进顶部约 10% 高度，区间带几乎不可见（总额口径下可见，反证量程问题）。
2. 瀑布图增量步进柱（-0.04/-0.08）高度不足 3px 且与「本期」总量柱同为深青色，无正负色区分。
3. 知识图谱三类节点（产品/药材/工序）颜色无图例，语义只能靠猜；节点簇只占画布中部 1/3，上下大面积空白。

**数据与格式**
4. 负零缺陷：季度模式出现「-0.00元/盒」两条（伴随 -0.81%/-0.45% 负占比）。
5. 数字口径不一：千分位有无混用（614,950.00 vs 105000.00/35000.00盒）、小数位随意（16450.0 vs 16450.00）同屏并存；未统一走 `fmt()`。

**文案与模板拼接**
6. 「建议：」行与所在卡片的假设正文**逐字重复**，数据分析页 ≥3 处、对标页 ≥4 处，成片冗余（疑似 `hypothesis` 渲染后又原样拼入建议字段）。
7. 同一免责句在数据分析页重复约 15 次，稀释「重点分析」信号。
8. 空态文案误用：「暂无待解析数据」复用于报告模板/知识库页（该处并非数据问题）。
9. 按钮命名混用：解析数据/解析报告模板/构建知识索引/确认/保存设置，同语义不同词。

**样式体系**
10. token 漂移：`--bg` 未在 `:root` 定义，锚点导航回退暖米色 #f4f5ed，与页面冷灰 #f4f7f9 形成一条肉眼可见色带（色温相反）。
11. 模型配置页「接入方式」分段控件右对齐至列尾，与标签之间大片空白，且违背全表单「标签正上方左对齐」模式（两页同根因）。
12. 同屏两套筛选器样式：对标页顶部全局筛选（白卡+11px 灰标签）vs 分析/基准工厂选择（裸 14px 深色标签、无容器）。
13. 占位符转义错误：`placeholder="C:\\keys\\provider.key"` 等字面显示双反斜杠（ModelConfigForm.tsx:127、ModelPages.tsx:54）。
14. 侧栏品牌副标题「…报告系统」断行后末字孤行悬挂，10 页全部出现。
15. 三个导入页暴露浏览器原生英文控件「Choose File / No file chosen」，与中文界面及控件体系割裂。
16. 主 CTA 初始禁用态呈 50% 半透明褪色（白字对合成底约 1.9–2.0:1），上传/构建索引/解析三页首屏像渲染故障；第二轮确认禁用态与可用态按钮同色难辨。

**信息架构**
17. 报告生成：验收状态卡「通过」与「待评」同为深灰 rgb(34,52,62)，无底色/形状差异，无法扫读；三条历史报告标题完全相同且无时间戳/版本号（DOM 确认），无法分辨先后。
18. 对标页原料明细表 8 行重复完全相同的 工厂/产品/规格/月份/产量 五列，宽度浪费且扫读困难；双列对比区右列大面积空白。
19. 数据分析页整页 6500+ CSS px、23 个同名「查看证据依据」按钮（无 aria-label 区分）、图表 canvas 无替代文本；向量模型页回显本机绝对路径（D:\重庆市AI大赛\…），产品化欠妥；数据分析模型页缺「已配置」徽章与提取模型页不一致。

## 六、值得保留的亮点
