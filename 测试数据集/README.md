# 测试数据集（药衡智析演示用）

> **本目录全部文件均为测试数据**：企业（测试药厂）、产品（测试板蓝根颗粒、测试六味地黄胶囊）、
> 工厂（测试一厂/测试二厂）、行业基准区间与知识文档全部为独立编制的虚构内容，
> 与任何真实企业、真实行业数值无关。仅用于“药衡智析”功能演示与验收，
> **不得作为现实经营、采购或投资决策的依据**。

## 目录结构

| 子目录 | 内容 | 说明 |
| --- | --- | --- |
| `业务数据/` | 成本汇总（2025/2026）、原材料消耗明细、制造费用明细、人工工时明细、预算数据、**行业参考数据** | CSV，文件名带 `测试数据_` 前缀；工厂/产品名带“测试”字样；数值勾稽自洽，可直接通过后端质量校验 |
| `行业参考数据/` | 中药行业成本基准（虚构 P25/P50/P75 区间） | 通过业务数据页的“行业参考数据”类型上传，出现在分析页「行业参考数据」区块 |
| `知识文档/` | 产品知识、行业成本参考说明 | 通过知识库页上传并构建索引，作为证据检索来源 |
| `报告模板/` | 月度成本分析报告模板 | 由已验证可解析的模板改写，企业名带“（测试数据）”标注 |

## 测试文件管理约定

1. **命名**：一律以 `测试数据_` 开头；内容中的企业与产品一律带“测试”字样。
2. **来源可追溯**：业务 CSV 由本目录 `make_test_dataset.py` 从仓库工作区的 `导入示例/` 派生生成
   （`导入示例/` 未入库，仅存在于本机工作区；全新克隆环境直接使用本目录已生成的文件即可，
   无需重新生成）。行业参考与知识文档在本目录内编制。不要手改生成文件，改规则后重新生成。
3. **与真实数据隔离**：真实/赛题数据不得混入本目录；本目录文件只应上传到演示或测试环境。
4. **重新生成**：`python make_test_dataset.py`（幂等，覆盖本目录生成物）。

## 一键导入运行中的后端

```bash
cd 测试数据集
python make_test_dataset.py        # 生成/刷新数据文件
python seed_test_data.py           # 上传 → 统一解析发布 → 知识库构建
```

脚本走公开 API（等价于页面手工上传）：上传业务数据（含行业参考）→ 知识文档 →
报告模板 → `POST /api/data/parse` 统一解析发布 → `POST /api/kb/build` 建库。
成功后打印 `context_id`（形如 `pharmaceutical:imp-xxxxxxxx`）。

## 验证要点（导入完成后）

- 「数据中心 · 业务数据」：全部文件状态“已解析”，无待解析残留。
- 「成本分析」：选择测试药厂任一产品/月份，「行业参考数据」区块出现基准行，
  并标注“行业参考来自上传文件（…）；为外部基准参考（通常为测试数据…）”。
- 「证据检索」（知识库页）：输入“提取收率”或“材料成本占比”可命中测试知识文档。
- 「分析报告」生成后：解释的建议/假设可引用上述证据；“查看证据依据”不为空。
