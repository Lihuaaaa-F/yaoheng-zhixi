# 通用制造成本框架

此包只提供可复用合同与报告章节，没有企业、业务数据或行业效果演示。数据中心发布用户确认的数据后，才注册独立企业上下文并在目录中出现；赛题演示继续使用原制药数据。

通用部分包括独立成本与产量事实、期间聚合、单位成本、环比/同比/预算、要素贡献、同口径跨厂对标、报告及任务流程。币种、数量单位、产品规格、责任人和知识来源属于企业配置，不从制药题包继承。没有明细和知识时，系统明确说明限制。

新增行业政策时，可复制本包配置并注册经过测试的专用策略，或向已有包注册新的企业。特殊计量转换、工序驱动、分配规则与行业基准必须由实施者定义和验证；上传配置不能执行任意代码。详见应用 `docs/industry/development.md`。
