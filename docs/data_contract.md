# 成本与产量合同

权威类型见 `05_原型/backend/pharma/industry.py`；字段映射、制药语义校验见行业包。金额Decimal且必须有限，数量独立于金额事实，不随明细连接重复归集。原件不改，默认回归使用独立合成数据。题包原件可按已授权公开范围保留；直接消费题包的扩展集成检查须显式设置 `PHARMA_TEST_COMPETITION_DATA=1`，不把题包或其派生值标成独立合成样例。

源表金额勾稽及快照归因勾稽共用绝对容差 `0.000001`；超过容差拒绝，容差内保留原始差额，不调整数值凑平。展示金额统一使用 Decimal `ROUND_HALF_UP`。

CostFact/QuantityFact共同绑定企业、工厂、产品版本、期间粒度、成本对象/粒度、情景、政策、完工范围、来源行及快照、导入/驱动重建来源模式。成本另含要素/父层级、明细或汇总、币种、计量单位、金额；数量另含数量与单位。父子汇总或重复汇总不得双计，互不包含的要素允许不同层级。

比较先核对规格、单位、币种、完整期间、WIP、政策和成本来源。合法环比/同比/预算/标准对比允许日期/情景按定义不同。SI换算与显式产品换算须校验；政策桥接必须绑定比较场景、调整金额及证据引用。无依据不可推算件↔kg、包装或密度，不自动跨币种加总。

OptionalFact为采购/BOM/配方/机时/工时/能耗/批次等类型扩展入口；本轮证明机时/合格件和能耗/合格kg，未建设全量生产业务。缺明细不造严格价量分解，维修事件不等于已证实净原因。

AnalysisContext绑定企业配置内容、数据/知识快照、行业/政策/公式/模板版本。模型/提示/检索器/嵌入/参数另进生成缓存键。参考行业包、同包企业注册、原子CSV快照与标准测试详见industry/development.md。
