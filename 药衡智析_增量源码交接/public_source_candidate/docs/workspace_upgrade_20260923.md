## 当前追加改版：三栏与全部上传数据

本轮采用左侧导航、中间工作区、右侧对话三个悬浮面板。运行状态移到左栏；中间不再显示成本分析标题或数据范围选择。筛选与分区导航固定，正文独立滚动。模型连接中的助手用途命名为“对话助手”。

## 用户能看到的变化

工作台采用统一的浅色企业界面：160px 左侧导航、可滚动分析区、可调整宽度的右侧助手。助手以 8px 圆角独立面板呈现，外边距 18px，输入栏固定于面板底部；圆环、型号、推理强度及发送按钮中心线对齐。常用筛选、图表、数值表和证据入口保持联动；小屏使用抽屉，筛选写入 URL，浏览器返回可恢复选择。统一字号、文字基线、控件高度、细边框、圆角、数字对齐和键盘焦点。

助手连接集中在“模型与设置 → 模型连接 → AI 助手（独立）”。输入框只保留上下文圆环、型号、推理强度与发送/停止按钮。删除常驻的连接位置与数字来源尾注。模型选择可读取服务端列表；手动添加型号在模型连接页完成。推理强度经厂商适配器转换；不支持时给出说明，不能仅凭控件已选中宣称服务端支持。

圆环彩色弧长表示预估输入占当前窗口的比例，不把预留输出当成已经使用的输入。上下文圆环颜色按扣除输出预留后的剩余比例从绿、蓝、黄到红连续变化；未知容量为灰色。悬停和键盘聚焦显示输入估算、配置窗口、输出预留和同型号、同快照的上次服务端用量。未提供通用模型分词器，所以输入量明确为 UTF-8 大小估算，不伪装精确 token 数；容量仅使用当前型号的用户配置，不猜测。预估超限时停止提交并提示调整。

顶栏部署位置来自 `PHARMA_DEPLOYMENT_MODE=local|cloud`，默认 local；Docker 本身不代表云部署。外网状态是最多每分钟一次不带凭据的 HTTPS HEAD 探测，不能证明所有外网、模型密钥或额度可用。数据更新时间来自当前数据快照首次成功载入/当前企业最近发布记录，不使用每次刷新时间冒充业务更新。

导入保留原件，构建成功后再切换可用数据。上传类型、文件名、预览、处理进度与失败原因可见；技术处理细节折叠，减少业务页面干扰。新的企业数据默认进入无样例数据的 `generic_manufacturing` 行业包，其他行业的合成夹具仍只用于测试。

## 助手执行边界

- 每轮绑定当前范围和不可变分析快照，最多四个本地只读工具、一次模型请求；报告后台任务不阻塞助手调度。
- 会话、消息、请求幂等键和确认状态保存到本机 SQLite。重启中断的进行中模型调用不会自动重发；取消后不发布迟到回答。服务商已经接收的请求可能仍计费用。
- 模型返回受 JSON Schema/Pydantic 约束；数字必须引用事实插槽，由程序填入标签、数值、单位。未绑定数字、指标角色错配、无依据因果断言和虚构已执行操作被拒绝，回退程序事实。
- 文档只作为不可信证据，不能触发工具权限或外部操作。历史只选同范围、同快照最近对话，不混入另一企业资料。
- “生成报告”“创建整改草稿”只形成待确认建议。确认时核对原数据版本，报告使用原快照；整改草稿还需补充负责人和期限，并在整改页再次确认才进入 RPA。送达不等于整改完成。

## 模型配置合同

`analysis`、`extraction`、`assistant` 分别保存连接。助手不回退到全局/报告密钥。保存一个路由不覆盖其他路由，空密钥保留原值，`clear_api_key: true` 解除引用但不删除密钥文件。密钥只写后端受限文件，不回显、不进入浏览器持久存储或仓库。改变地址不会把旧密钥发送到新地址。

模型连接可配置协议、服务地址、型号、鉴权模式、推理强度、temperature、top_p、输出上限和超时；本地兼容服务可无密钥。窗口元数据 `model_context_windows` 按型号存储，仅用于上下文显示，不发送给模型。环境变量优先于网页保存值，页面显示实际生效值。

| 接口 | 合同 |
|---|---|
| `GET /api/system/status?context_id=…` | 部署来源、探测结果、数据更新时间及依据 |
| `GET/PUT /api/settings/models` | 脱敏状态 / 合并指定路由设置 |
| `POST /api/settings/models/test?route=assistant` | 使用表单候选连接短请求，不保存；可能产生服务商费用 |
| `POST /api/settings/models/list?route=assistant` | 候选连接读取型号，密钥不进入 URL |
| `GET/POST /api/assistant/conversations` | 历史 / 新建会话 |
| `GET /api/assistant/conversations/{id}` | 消息和最新操作确认状态 |
| `POST /api/assistant/conversations/{id}/messages` | text、selection、client_request_id、可选型号/推理覆盖；返回异步 turn |
| `GET /api/assistant/turns/{id}` | 阶段、终态、失败原因 |
| `POST /api/assistant/turns/{id}/cancel` | 停止等待，保留提问 |
| `POST /api/assistant/proposals/{id}/confirm` | 幂等确认当前建议；版本变化拒绝 |
| `POST /api/assistant/context` | 当前输入估算；不发模型请求 |
| `GET /api/kb/sources/{source_id}?context_id=…` | 仅当前范围注册的原文文件 |

完整字段和范围限制以服务 `/docs` 中的请求模型为准。

## 同轮修复的计算与资料问题

季度和导入数据的归因直接使用所选分析快照，避免误用比赛月度数据。跨厂总额与单位口径分别计算，助手、报告绑定所选厂对。市场同向信号和跨厂前后变化只是核查线索，不称因果比例。预测区间覆盖按当前序列的滚动检验计算，不使用硬编码全局精度。

知识索引按企业范围和内容版本隔离，PDF 页码、DOCX 段落/表格位置和 TXT 编码可追溯。同名不同内容不覆盖已注册来源；构建失败不切换旧可用版本。混合扫描页缺文字时明确要求 OCR，不能把局部解析当完整成功。

图表浮层统一采用非 HTML 文本渲染，导入的产品、要素名称不能被当作 HTML 执行。对标新增 `explain=none` 只读基础分析模式，不触发模型请求或报告排队。

人工验收分数与三个质量维度必须由用户显式填写，上传凭证不再默认给满分和 PASS。

## 部署与兼容

保留轻量模块化单体，不新增 Redis、云数据库或独立聊天服务。Compose 中应用与后台任务使用非 root 用户；修复镜像指令和密钥挂载错误。网页保存的密钥在运行卷中复用。默认不阻塞启动下载向量模型，需下载时显式设置 `PHARMA_FETCH_EMBEDDING=1`。启动器支持实际 WSL 分发版与路径，新增更新构建入口；不会强推 Git、删除卷或覆盖原数据。
