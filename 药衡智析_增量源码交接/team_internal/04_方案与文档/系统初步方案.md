# 药衡智析：初版产品与技术方案

更新：2026-09-15；本文件原位替换旧设计，以已实现源码为准。初版服务于2026年重庆市AI大模型创新应用大赛创灵境企业赛题，目标是成本分析、报告、对标和模拟整改闭环。

## 产品流程

选择产品、工厂和期间→固定数据版本→确定性计算→中文关键词与向量混合检索→受约束模型解释→原Word模板及PDF→用户编辑确认建议→原题包mock模拟发送。看板、报告和任务引用相同分析快照；缺失预算、原料明细或基期明确N/A。

## 实际架构

React 19＋TypeScript＋Vite＋ECharts 前端静态打包，由 FastAPI 提供本地访问。Python 3.12项目虚拟环境；DuckDB查询不可变Parquet，Decimal计算金额；SQLite WAL保存分析快照、任务、模型记录及outbox，单个持久worker处理报告和发送。

检索使用PyMuPDF/python-docx/TXT轻量解析，jieba一致中文分词、SQLite FTS5 BM25、BGE量化ONNX CPU向量和Chroma本地存储，RRF按名次融合；LlamaIndex Core BaseRetriever/TextNode真实参与结果适配。生成默认DeepSeek `deepseek-flash`，同时保留OpenAI和Anthropic协议适配。

报告由原DOCX工作副本、XML位置绑定和python-docx生成，Matplotlib使用同一快照绘图，LibreOffice按任务隔离用户配置导出PDF。部署采用requirements及一键脚本，当前不依赖Docker daemon。

## 业务边界

三要素单位成本严格超过±10%才触发单位告警；总额告警另算且受产量影响。原料单位消耗成本不是采购单价或实物耗用量，行情不是企业采购价；设备事件不能证明月度净因果。季度单位成本按产量加权；不同规格每盒成本不混为集团效率指标。二厂缺预算和明细时不推算。生产/GMP变更须人工批准。

初版不包含预测、完整知识图谱、开放式Agent、多模型互审、真实ERP/微信、硬件或多租户。情景变异只作隔离测试，不回写比赛原件。RPA `sent`只表示原mock完成模拟发送，不代表真实人员收到或整改完成。
