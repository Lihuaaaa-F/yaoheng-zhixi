# 成本预测模型

采用现有固定参数 Holt 线性指数平滑，独立入口负责读取数据、恢复状态和导出评测，不改变系统中的预测算法。

## 运行

在项目根目录执行，Python 3.12，仅使用标准库：

```bash
python3 05_原型/scripts/forecast_cli.py \
  --input '00_赛题原始资料/模拟数据_V1.1_净化解压/创灵境_考题模拟数据/01_成本明细数据/中药一厂_成本汇总_2026年1-6月.csv' \
  --horizon 3 --state-out /tmp/药衡预测状态.json --output /tmp/药衡预测结果.json
python3 05_原型/scripts/forecast_cli.py \
  --state-in /tmp/药衡预测状态.json --horizon 3 --output /tmp/药衡预测恢复结果.json
```

共享虚拟环境可通过 `PHARMA_PYTHON` 指定；将上例 `python3` 换成 `"$PHARMA_PYTHON"` 即可。两种入口在相同状态和步长下产生字节一致的结果。状态保存训练历史、参数、方法版本和输入校验值，推理时确定性重建水平与趋势，无另行下载的模型权重。

## 输入、目标和方法

输入为UTF-8 CSV，按工厂、产品和月份分组。目标包括单位成本、直接材料、直接人工、制造费用（元/盒）和总成本（元）；各目标单独拟合，不将不同单位的误差混合求均值。本例采用原题中药一厂3个产品的2026年1至6月汇总，每条序列6个月，共15条序列。默认预测未来3个月，可选1至6个月。

固定参数α=0.6、β=0.3，不在本次评测上调参。使用训练前缀的前2至3点最小二乘初始化水平和斜率，再按Holt递推吸收历史观测。源码入口为 `05_原型/backend/pharma/forecasting.py`，独立运行入口为 `05_原型/scripts/forecast_cli.py`。

不足3个连续有效月份、缺月、缺失或无效观测不输出预测，不补零。重复月份明确拒绝；CSV在分组后按月份排序。异常值不静默删除或缩尾，需要业务核实后修正源数据；负预测保留并给出警示，不用截断掩盖模型局限。

## 时间顺序评测

采用扩展训练窗的一步滚动留出：1—3月训练预测4月，1—4月预测5月，1—5月预测6月。每序列3个原点，共45个检验点。每次初始化、拟合与波动范围都只使用该原点之前的观测，不使用未来值、不随机打乱，也不从全序列预估参数。朴素基线为上月值。误差采用未舍入的内部预测计算，JSON另附每个原点的训练截止月、实际值、预测和基线，便于复算。

## 波动范围和限制

范围为点预测±训练内一步残差均方根（倍数1.0），没有假设覆盖概率。留出覆盖统计与各训练前缀逐次重建，采用浮点相对容差，与现有实现一致。只有当前样本的一步覆盖实测，不能称为已验证置信区间；范围不随步长扩张，也未经多步覆盖验证。

每条历史只有6个月，留出只有3点，无法支持季节项、长期趋势可靠性或统计显著性结论；总成本预测尤其应作为探索参考。生产决策需要更长历史、异常事件记录及独立未来数据再验证。预测不是预算承诺。
