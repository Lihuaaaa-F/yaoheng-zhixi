## 使用行为

- **生成报告**：同版本结果可复用，避免重复消耗。
- **重新调用模型**：新建任务，保留旧任务与来源；不读取旧模型缓存。正在执行的同一新调用任务可幂等复用。
- **仅修复产物**：复用已有解释，重新生成独立文件，不新增模型调用，不替换原文件。

网站业务报告验收与比赛评测评分独立。机器能力通过且只等待人工评审时，规则建议仅更新看板；模型、检索或产物失败不能当作合格报告。

## 演示与交付范围

演示顺序：选择 S1 条件 → 生成报告并说明模型状态 → 看板结构与热力图 → 跨厂三步法与知识来源 → 下载 Word/PDF → 编辑整改草稿 → 确认后发送本地模拟 RPA → 核对回执和重复操作。录制前先确认模型、真实向量索引和本地模拟服务就绪。视频由用户人工录制，限制在五分钟内。

视频仍是缺失的必交物；PPT 为决赛阶段条件性必交。图谱十条查询对照未显示正增益；规则式决策不称为模型自主规划。预测保留既有算法，三个产品的总成本预测弱于朴素基线，详见 [预测评测](forecast/README.md)。不同任务使用同一模型的多个连接不计多模型协作。未新增其他行业演示。
