# 审查修复与回归范围

本修复基于 main 的 `958bb20`。审查依据为问题清单；其中版本号、行号和旧测试数量不作为当前验收结果。当前机器结果见 [current_run.json](../current_run.json)，历史模型调用、评测样本和真人评分保持原版本关联，不迁移到新生成文件。

| 范围 | 原因与修复 |
|---|---|
| 报告验收查询 | 重算缺少任务状态边界；仅完成态可重算，并在 SQL 更新中重复约束状态。排队、运行、失败任务均保持原状态。 |
| 后台任务与助手 | 循环外异常导致线程退出；初始化、心跳、数据库调度失败进入有间隔的恢复循环。助手知识检索遇 SQLite 错误时保留确定性指标。 |
| Windows 持久化与进程管理 | 默认编码不能表达完整模型文本；JSON 明确 UTF-8。停止服务核对 PID 与进程创建时间，缺失凭据不终止进程。运行临时目录归项目管理，缺失心跳不显示为零秒，字体探针失败仍输出 JSON。 |
| 知识索引与来源 | 新鲜度失败曾阻断旧索引；自动读取按失败输入指纹抑制重复构建，显式构建可重试，旧有效版本以降级状态服务。清单原子写入并可恢复损坏清单，同名源分别保留指纹，JSON 知识源参与快照。 |
| 向量切换 | 类型检查未检查非有限数，异常回滚范围不完整；拒绝 NaN/Inf，不接受与实际推理不符的适配配置，异常恢复配置与旧索引。 |
| 检索合同与叙事 | 保留 document_version；术语读取使用有界缓存；剂量关系保留实际单位；拒绝把总额指标附加单位成本量纲。检索成功、召回状态与证据充分性继续分离，更新现行提示合同文档。 |
| 数据导入 | 预览失败前已写原件，导致孤儿上传；先验证后落盘，已有有效孤儿可重传恢复。一个要素不能映射到两列金额，明细行可累加的语义不变。 |
| 指标与归因 | 展示舍入、勾稽容差不一致；统一 Decimal ROUND_HALF_UP 与准入容差，保留原值。缺材料要素不借用第一要素分母，零变化不称对照反向。 |
| 行业与决策 | 数据缓存无上限改为有界缓存；修正预测初始化文档。产物损坏对应的 artifact_health 可作为模型说明信号，修正自相矛盾的提示约束。 |
| 报告模板与图表 | 绑定下限错误地固定为原模板的 70 项；新合同核对当前模板全部数字绑定，旧产物保留旧规则。修正目录 EMU/twip 换算，文本数值使用 Decimal；缺失变动不补零绘制桥接，缺锚点返回明确错误。 |
| 整改闭环 | HTTP 422 拒收后缺少恢复入口；展示错误，只允许明确拒收任务编辑回草稿，并重新进行用户确认。SENDING 与送达未知仍只查询，不自动重发。署名接责不等于整改完成。 |
| 前端 | 任务通知按种类定位；统一真实及转义换行/tab；图表与表格保留缺失变动；评审读取错误、加载中、空记录分别显示并可重试。 |
| 回归边界 | 增加署名接责、RPA 后续状态、SENDING 恢复、哈希变化拒绝、召回三态、重排越界、修复预算边界测试；题包数值相关测试改为显式启用，默认独立合成。 |

本次没有据已被独立复核推翻的六条发现修改模型档位、回环设计、Windows 环境变量过滤、任务并发去重、密钥参数类型或模型探针异常范围。

基础验证不调用真实云模型。浏览器回归使用独立合成接口，不能作为真实模型、向量服务、真人评分或 Word/PDF 视觉一致性的验收。Windows 创建时间接口在本轮以注入方式覆盖，真实 Windows/Word COM 仍需目标机器验证。当前 Linux 环境执行了实际 LibreOffice PDF 转换回归。
