# ADR 0001：确定性成本引擎拥有数值真相

状态：Accepted；原决定2026-08-26，按实现更新2026-09-15。

成本金额、单位成本、月份连接、贡献度、季度加权和对标分母均由版本化Decimal引擎计算。`metrics.analyze`输出固定快照，保留原值、展示值、单位、公式、分子分母、比较期、行键和源哈希；看板与报告复用它。生成模型选择指标/证据引用并解释待核查原因，不重新计算数值。

原料单位消耗成本只有“元/盒”，没有企业采购价与实物用量。设备故障与成本走势仅支持假设，不能把维修费再加到已汇总成本。无基期、零分母和缺完整季度均明确N/A；总额与单位告警分开。同一盒规格才可对比，行业每支/袋/粒换算经过规格核验。

此决定让数值能够独立复算，也要求报告位置绑定及引用支持检查。词面引用约束不等于证明因果，归因合理性仍须真人评分。
