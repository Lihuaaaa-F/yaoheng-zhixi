# 领域语言

本文件只定义项目中的业务概念。实现细节与技术取舍见 `docs/adr/`。

- **成本对象**：需要单独归集、计算和分析成本的产品、批次、工厂或期间组合。
- **单位成本**：指定成本对象在指定期间的总成本除以产量；展示时必须同时携带单位、期间、工厂和产品。
- **直接材料**：能够经济、明确地归属于成本对象的原料及辅料成本。
- **直接人工**：能够直接归属于成本对象的生产人员薪酬与相关支出。
- **制造费用**：不能直接归属于单一成本对象、需要按规则分配的生产间接成本。
- **成本动因**：与成本变动存在可测量关系的业务量、价格、效率、配方、工艺、设备或质量因素。
- **成本事件**：可能影响成本的外部或内部事实，例如市场价格变化、设备停机、工艺变更；事件本身不等同于已验证成本动因。
- **证据单元**：可独立引用与复核的数据行、计算式、文档页码或接口响应，含来源、版本、哈希与时间。
- **归因结论**：由确定性计算复现的成本变动额、贡献率或差异率。
- **证据支持假设**：方向与时间上得到文档或市场信息支持，但因缺少必要字段尚不能完成定量因果分解的解释。
- **证据不足**：现有数据不能可靠支持的因果说法；系统必须明确标记，不能由模型补全。
- **对标基准**：用于比较的预算、历史同期、上期、同产品其他工厂或行业数据；必须显式显示基准期间与口径。
- **分析场景**：产品、工厂、期间、基准、口径版本与阈值配置的完整组合。
- **整改任务**：从分析结论生成、可幂等推送并可追踪状态的行动项。


- **单位口径告警**：某一成本要素单位产出成本（制药包为每盒）的月度变动率严格超过±10%；恰好±10%不触发。
- **总额口径告警**：要素单位成本乘以当月产量所得金额的月度变动率严格超过±10%，同时受产量影响。
- **模拟送达**：原题包RPA已创建任务并模拟发送微信；不等于真实人员收到、确认或完成整改。
- **确认载荷**：用户确认时的任务内容，内容变化必须重新确认；确认只对应当前哈希。

- **行业包**：具有稳定ID及版本的语义映射、证据合同、可信计算策略与报告配置集合。行业名称与制造模式分开。
- **企业政策**：独立于行业的计量、规格、成本来源、标准版本和分摊口径。
- **分析上下文**：创建任务时冻结的企业/数据集、包、政策、数据/知识快照、模板与公式版本；后续切换不改变旧任务。
- **粒度与来源模式**：产品期间汇总和工单/批次明细不能混加；导入成本与按驱动重建成本需要明确桥接后才能比较。
- **专用可选事实**：机时、能耗等带单位、生产对象和核算范围的独立记录；缺少合法数据时能力降级，不由模型推测。
